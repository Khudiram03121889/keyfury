## Executive Overview & Master Strategy Index

**KeyFury** (`https://keyfury.in`) is a web-based 1v1 multiplayer brawler where mechanical QWERTY typing speed (Words Per Minute) directly dictates physical combat damage, hit combinations, and martial arts special moves between stickman fighters.

Traditional typing test platforms (such as *Monkeytype*, *TypeRacer*, and *10FastFingers*) possess massive organic search and social traffic but suffer from static, non-gamified UI experiences that lose player retention after short sessions. Conversely, traditional fighting games (*Street Fighter*, *Tekken*, *One Finger Death Punch*) offer visceral combat satisfaction but suffer from steep mechanical input learning curves.

KeyFury bridges this gap by merging **mechanical keyboard switch acoustics**, **high-speed touch typing flex**, and **instant 60 FPS stickman martial arts combat**.

## End-to-End Content Production Pipeline

To maintain a posting velocity of **2 to 3 videos per day**, the team utilizes a streamlined 4-step batch production assembly line.

```
+---------------------------------------------------------------------------------------------------+
|                                 STEP-BY-STEP PRODUCTION PIPELINE                                  |
+---------------------------------------------------------------------------------------------------+
|                                                                                                   |
|  [STEP 1: RECORDING] ──> [STEP 2: EDITING] ──> [STEP 3: AUDIO MIXING] ──> [STEP 4: PUBLISHING]    |
|  • OBS Studio 60FPS   • CapCut / Premiere    • Thock ASMR (+3dB)    • Title & Hashtags          |
|  • Dual cam + screen  • Single-word captions • Hit SFX (-1dB)       • Pinned Comment CTA        |
|  • High-gain thock mic• 1.1x speed ramp      • BGM (-18dB)          • IG Sound Tag Layer        |
|                                                                                                   |
+---------------------------------------------------------------------------------------------------+
```

### Step 1: High-Frame-Rate Recording Setup
1. Open OBS Studio with the `KeyFury Vertical` profile (1080x1920 @ 60 FPS, NVENC 15,000 Kbps).
2. Position primary desk camera pointing at mechanical keyboard setup (Hand-cam angle).
3. Ensure secondary camera captures creator face reaction or screen code.
4. Record raw 60 FPS gameplay sessions into `d:\Keyboard stickman warrior\renders\raw_gameplay\`.

### Step 2: CapCut / Premiere Pro Editing Assembly
1. Import raw clips into 9:16 vertical sequence timeline.
2. Cut opening frame (0:00) precisely on visual movement (stickman kick or shattered text).
3. Apply 1.1x subtle speed ramp to remove silent pauses between voiceover sentences.
4. Generate auto-captions; style with **Bebas Neue / Montserrat**, yellow highlights, 1-word pop-in animation.
5. Add directional screen shake effect on critical 10+ letter word completions.

### Step 3: Audio Layering & Mixing Matrix
* **Channel 1 (Thock ASMR):** Hard-panned left/right, boosted by **+3dB** (preserving raw switch acoustics).
* **Channel 2 (Combat Hit SFX):** Center channel, set to **-1dB** on word completions.
* **Channel 3 (Voiceover):** Crisp, compressed vocal track, set to **0dB** (loud and clear).
* **Channel 4 (Trending BGM):** Low-volume background track, set to **-18dB** to **-22dB** (adds algorithmic trend tag on IG Reels without obscuring ASMR).

### Step 4: Pre-Publishing Checklist
- [ ] Render file at **1080x1920 MP4 (H.264, 60 FPS)**.
- [ ] Confirm video duration is between **18 seconds and 28 seconds** (Optimal loop window).
- [ ] Confirm creator watermark `KEYFURY.IN` is present in upper safe zone at 40% opacity.
- [ ] Confirm zero third-party watermarks (No TikTok or CapCut logos).
- [ ] Select dynamic action thumbnail frame featuring stickman mid-kick or WPM spike.
- [ ] Prepare pinned comment with immediate call-to-action link: `⚔️ Play 1v1 free at https://keyfury.in`.
