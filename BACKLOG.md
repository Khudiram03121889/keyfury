# KeyFury - Backlog & Deferred Features

The following features are explicitly out of scope for the 1v1 Founder Beta release and are captured here for future milestones:

- AI / bot opponents and single-player practice modes.
- MMR ratings, ranked queue, global leaderboards, seasons, and tournaments.
- User accounts beyond anonymous/guest identity (e.g. Email / OAuth / Discord login).
- Customisation, skins, cosmetics, inventory, battle pass, or virtual currency.
- Spectator mode, match replay viewer, video export, or highlight clip generator.
- Mobile browser controls, touch inputs, or custom keyboard layout mapping (Dvorak/Colemak).
- Multi-arena environments, character movement, physics collisions, weapons, or special abilities.
- School/child-directed privacy features and classroom dashboards.
